<threat_model>
## ASVS Level 1 Threat Analysis

- **T-04-01: Lockscreen Keystroke Injection & Unauthorized Microphone Activation (ASVS 1.1.2 - Elevation of Privilege / Tampering)**
  - *Description:* If desktop keybindings specify `locked = true` (or use the `bindl` dispatcher), a passerby could press `SUPER + SHIFT + M` while the workstation screen is locked with `hyprlock`, activating the microphone and injecting transcribed text into whatever window had focus before locking.
  - *Severity:* High
  - *Mitigation:* Enforce unlocked-only execution (`locked = false` / standard `hl.bind`) per D-04. Hyprland suppresses standard `hl.bind` shortcuts whenever a session lockscreen is active.
- **T-04-03: Dotfiles Stow Symlink Destruction & Unversioned Drift (ASVS 8.3.1 - Tampering / Data Loss)**
  - *Description:* The user manages `~/.config/hypr/custom/keybinds.lua` as a GNU Stow symlink pointing to `~/.dotfiles/stow/hypr/.config/hypr/custom/keybinds.lua`. Naive atomic file replacement (e.g. writing a temporary file and calling `os.replace` on the symlink) severs the symlink, replacing it with an untracked local file and silently breaking version control.
  - *Severity:* High
  - *Mitigation:* The installer resolves the real target path (`keybinds_path.resolve()`) before writing and modifies the file in-place per D-07, ensuring the symlink remains intact and changes are tracked in git.
- **T-04-05: Keybinding Collision / Upstream Shortcut Hijacking (ASVS 11.1.4 - Denial of Service)**
  - *Description:* Upstream `dots-hyprland` binds `SUPER + T` to open a terminal. Adding `SUPER + T` for TTS without unbinding causes both the terminal emulator and TTS synthesis to launch concurrently on every keypress.
  - *Severity:* Medium
  - *Mitigation:* Explicitly generate `hl.unbind("SUPER + T")` inside the delimited configuration block prior to binding `SUPER + T` per D-02. Terminal accessibility remains preserved via existing primary shortcuts `SUPER + Return` and `CTRL + ALT + T` per D-03.
- **T-04-08: Incomplete PATH Execution Failure in Hyprland Session (ASVS 10.3.1 - Denial of Service)**
  - *Description:* Hyprland launched from a display manager or systemd service may not inherit interactive shell `$PATH` additions like `~/.local/bin`, causing `voice` commands to fail silently.
  - *Severity:* Medium
  - *Mitigation:* Use the fully expanded path `HOME .. "/.local/bin/voice"` (or `$HOME/.local/bin/voice`) in `hl.dsp.exec_cmd` per D-10 to guarantee binary discovery regardless of session environment variables.
</threat_model>
