# Plan 02-02: Dual Clipboard Persistence, CLI Configuration & Verification

## Executive Summary

Plan 02-02 completes the Wayland keystroke injection implementation for Phase 2. It implements the dual-action clipboard persistence model (unconditionally buffering transcripts via `wl-copy` immediately upon transcription and prior to typing), desktop failure alerting via `notify-send` when typing fails, pure Wayland environment detection in `notify()`, CLI argument parsing with environment variable overrides (`--wayland-backend`, `--pre-type-delay`, `--keep-newlines`), non-negative delay clamping, and serialization of all new options into `background_argv()` for detached daemon workers. Finally, it documents the Wayland stack in `docs/DEPENDENCIES.md` and `README.md`, and runs the full automated unit test suite and system verification checks.

<threat_model>
## ASVS Level 1 Threat Analysis

- **T-02-04: Clipboard Data Exposure or Unintended Overwrite (ASVS 8.3.1)**
  - *Description:* Unconditionally copying transcripts to the system clipboard exposes transcribed speech to any application reading the Wayland clipboard buffer, and overwrites existing clipboard contents.
  - *Severity:* Low / Accepted Design Tradeoff
  - *Mitigation:* In desktop dictation, the user explicitly activates push-to-talk to generate text for immediate insertion. Dual persistence (D-16) ensures that if window focus shifts, keystrokes are dropped, or typing crashes, speech is never lost. Transcripts are placed into the system clipboard via standard `wl-copy`. When `--output-method paste` is used, the clipboard retains the dictated text without attempting fragile restore routines per D-17.
- **T-02-05: Background Worker Configuration Desynchronization (ASVS 5.3.4)**
  - *Description:* When toggling background recording via `voicemode --toggle`, CLI flags passed by the user could be lost if not forwarded to the detached daemon worker, causing the worker to revert silently to defaults.
  - *Severity:* Medium
  - *Mitigation:* `background_argv()` explicitly serializes `--wayland-backend`, `--pre-type-delay`, and `--keep-newlines`/`--no-keep-newlines` into the detached process argv array, ensuring strict parameter consistency between foreground CLI invocations and detached background workers.
</threat_model>
