<threat_model>
## ASVS Level 1 Threat Analysis

- **T-03-04: Denial of Service / Process Hang via Unresponsive Wayland Client (ASVS 11.1.4)**
  - *Description:* If an application holding the Wayland primary selection hangs, deadlocks, or crashes, `wl-paste --primary` can block indefinitely, freezing hotkey triggers and daemon threads.
  - *Severity:* High
  - *Mitigation:* Enforce a strict 1.0s timeout on all `wl-paste` commands (`subprocess.run(..., timeout=1.0)`) per D-05. If `subprocess.TimeoutExpired` occurs, catch it cleanly and treat the selection as empty.
- **T-03-05: Sensitive Clipboard Overwrite / Data Destruction (ASVS 8.3.1)**
  - *Description:* Naive selection reading scripts often simulate `Ctrl+C` into the regular clipboard, clobbering copied passwords, tokens, or code snippets that the user copied previously.
  - *Severity:* High
  - *Mitigation:* Read the Wayland primary selection directly via `wl-paste --primary` without touching the standard clipboard or injecting synthetic copy keystrokes per D-04 and D-09. Leave the on-screen highlight intact.
- **T-03-06: Synthesis Resource Exhaustion via Unbounded Selection (ASVS 11.1.4)**
  - *Description:* Accidental selection of large files (e.g. a 50MB system log or entire book) would trigger hours of CPU synthesis and generate gigabytes of uncompressed WAV data in `$STATE_DIR`.
  - *Severity:* Medium
  - *Mitigation:* Enforce an upfront length limit of 5,000 characters (~1,000 words / ~6 minutes of speech) via `DEFAULT_TTS_MAX_CHARS` per D-06. Truncate text before background worker dispatch and notify the user via a desktop warning toast.
- **T-03-07: Disk Space & Inode Exhaustion from Stale Temp Files (ASVS 12.2.1)**
  - *Description:* If worker processes are killed uncleanly (e.g. `SIGKILL` or system power loss), temporary WAV and text files (`voice-tts-*.wav`) accumulate in `STATE_DIR`, eventually filling `/run/user/<uid>` or the state filesystem.
  - *Severity:* Medium
  - *Mitigation:* Implement opportunistic garbage collection in `cleanup_stale_tts_files` to purge all temporary files older than 30 minutes on startup and stop per D-20.
- **T-03-08: Bogus Desktop Error Toasts on User Interruption (ASVS 11.1.4)**
  - *Description:* When user stops playback with `Super+T` or `--stop-tts`, `os.killpg(pid, SIGTERM)` kills `ffplay`. Unfiltered `subprocess.CalledProcessError` would interpret exit code -15 as a crash and display an alarming error toast.
  - *Severity:* Low
  - *Mitigation:* Filter intentional termination exit codes (-15, -2, 255, 143, 130) in `play_tts_audio` and convert them to clean `KeyboardInterrupt`, showing only a brief "Speech stopped." confirmation per D-18 and D-19.
</threat_model>

   - Unicode punctuation normalization: em-dashes `—` and en-dashes `–` to `, `, curly quotes `’` / `“` / `”` to straight quotes.
