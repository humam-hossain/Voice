<threat_model>
## ASVS Level 1 Threat Analysis

- **T-03-01: Asset Corruption or Partial Download Denial of Service (ASVS 10.3.2)**
  - *Description:* Network interruptions during multi-megabyte binary downloads (~325MB ONNX model) could leave truncated or corrupted files on disk. Subsequent ONNX runtime instantiation would crash during speech synthesis.
  - *Severity:* High
  - *Mitigation:* Downloads stream into `.tmp` sibling files (`kokoro-v1.0.onnx.tmp`, `voices-v1.0.bin.tmp`) and are validated against strict byte size guards (>300,000,000 bytes for model, >20,000,000 bytes for voices) before atomic replacement via `Path.replace()` per D-02 and D-03. Failed downloads clean up temporary files immediately.
- **T-03-02: Silent Privacy Leak via Unintended Cloud Fallback (ASVS 1.1.2)**
  - *Description:* If Kokoro models are missing or corrupted, falling back automatically to Microsoft Edge TTS (`edge-tts`) transmits user-selected screen text or confidential dictation to Microsoft cloud servers without explicit user consent.
  - *Severity:* High
  - *Mitigation:* Enforce strict offline-first privacy per D-15. When Kokoro assets are missing, never fall back to Edge TTS. Display an explicit desktop error notification and console guidance instructing the user to run `voice.py --download-tts-assets`.
- **T-03-03: Process Crash via Unclamped Speed Parameter (ASVS 11.1.4)**
  - *Description:* `kokoro-onnx` has a hard internal assertion `assert speed >= 0.5 and speed <= 2.0`. A user setting `VOICE_TTS_SPEED=2.5` or `--tts-speed 0.3` crashes the background worker with an unhandled `AssertionError`.
  - *Severity:* Medium
  - *Mitigation:* Explicitly clamp speech speed to `[0.5, 2.0]` via `clamp_tts_speed()` before calling `kokoro.create()` per D-14.
</threat_model>
