<threat_model>
## ASVS Level 1 Threat Analysis

- **T-05-01: Unauthorized Audio Sniffing & Process Impersonation (ASVS 1.1.2 - Information Disclosure / Spoofing)**
  - *Description:* A malicious local unprivileged process creates a crafted PID file in `$XDG_RUNTIME_DIR/voice-stt/` pointing to a sensitive system daemon to trigger accidental termination via `--kill`, or inspects temporary recordings.
  - *Severity:* High
  - *Mitigation:* `process_alive(pid)` strictly reads `/proc/{pid}/cmdline` and asserts the process invocation contains valid voicemode tokens (`voice`, `python`, `voicemode`) before interacting. PID directory is locked to mode `0700` tmpfs.
- **T-05-02: Arbitrary Command Injection via Compositor IPC (ASVS 5.3.1 - Injection)**
  - *Description:* If `hyprctl activewindow -j` output containing window class or title with shell metacharacters is evaluated insecurely in shell strings during window inspection, arbitrary code could execute.
  - *Severity:* High
  - *Mitigation:* `hyprctl` is invoked using argument lists `["hyprctl", "activewindow", "-j"]` with `subprocess.run(shell=False)` and parsed using Python's standard `json.loads`. Window attributes are treated strictly as read-only data strings.
- **T-05-03: Dotfiles Stow Symlink Decoupling during Diagnostic Checks (ASVS 8.3.1 - Tampering / Data Loss)**
  - *Description:* Diagnostic checks or remediation helpers reading `~/.config/hypr/custom/keybinds.lua` might recreate or unlink the symlink pointing to the user's version-controlled dotfiles (`~/.dotfiles/stow/hypr/...`).
  - *Severity:* High
  - *Mitigation:* Diagnostic checks explicitly assert `is_symlink()` and resolve targets via `Path.resolve()` without modifying the symlink structure.
- **T-05-04: Daemon Denial of Service via Stale PID File Locks (ASVS 11.1.4 - Denial of Service)**
  - *Description:* A crashed or SIGKILLed recording daemon leaves `recorder.pid` containing `<PID> recording`. Subsequent hotkey toggles fail with "Voice STT is currently transcribing" and refuse to record.
  - *Severity:* High
  - *Mitigation:* `voice --doctor` detects stale PID files where `process_alive(pid)` is false, and `voice --kill` cleans orphan PID files and resets daemon state to idle.
</threat_model>

<specless_probe_coverage>
### Edge Case & Boundary Coverage Probes
- **Empty / Single-element / Null Input (VERIF-01, VERIF-02):**
  - If `hyprctl activewindow -j` returns `{}` (empty workspace or no focused client), `hyprctl_active_window()` returns `None` safely without `KeyError` and prompts the user to focus a valid window.
  - If typing payload or transcription output is empty, `type_text()` returns `False` immediately without calling `wtype` (preventing hung processes or parameter rejection).
  - If selection text is empty or whitespace, TTS emits a clear notice ("No selected text or clipboard text") and exits cleanly with 0 without synthesizing audio.
- **Character Encoding & Normalization (VERIF-01, VERIF-02):**
  - All test payloads containing special symbols (`{}[]()$"'\`), unicode quotes, and newlines are encoded as UTF-8 (NFC normalized) and passed directly via stdin to `wtype -` with a pre-type delay (>0ms) to ensure consistent character reproduction across pure Wayland and XWayland windows.
</specless_probe_coverage>

     - Kokoro check: checks `models/kokoro/kokoro-v1.0.onnx` (stat size >= 300,000,000 bytes) and `models/kokoro/voices-v1.0.bin` (stat size >= 20,000,000 bytes). If missing or undersized, remediation hint is `"scripts/download-kokoro-assets.sh"` per D-09, D-10.
   - `check_hyprland_keybinds_status(config_path: Path | None = None) -> tuple[bool, str, str]`:
     - Resolves `path = config_path if config_path is not None else HYPRLAND_CUSTOM_KEYBINDS_PATH`.
     - Asserts `path.exists()`, checks `path.is_symlink()`, resolves real path `path.resolve()`, and reads content per D-09, D-15.
     - Verifies presence of delimited block (`-- voicemode start`), `SUPER + SHIFT + M` (`--toggle`), `SUPER + T` (`--speak-selection`), and `hl.unbind("SUPER + T")`.
     - If missing or incomplete, remediation hint is `"Run: voice --install-hotkey"` per D-10.
     - Returns status including symlink destination info (e.g. `Verified (symlink -> ~/.dotfiles/stow/hypr/...)`).
   - `check_daemon_pid_health() -> list[tuple[str, bool, str, str]]`:
     - Checks `PID_FILE` (`recorder.pid`) and `TTS_PID_FILE` (`tts.pid`) per D-11.
     - If PID file exists, reads PID and state token via `read_pid_state()`.
     - Evaluates `process_alive(pid)`.
     - If PID is alive: returns `(True, f"Running (PID {pid}, state: {state})", "")`.
     - If PID is dead / process not found: returns `(False, f"Stale lock (PID {pid} dead, state: {state})", "Recover with: voice --kill (inspect voice --log)")` per D-11.
     - If no PID file exists: returns `(True, "Idle (no PID file)", "")`.
   - `kill_all_daemons(args: argparse.Namespace) -> int`:
     - For both recorder daemon and TTS background player, inspects PID file.
     - If alive, sends `os.kill(pid, signal.SIGTERM)`.
     - Unlinks PID files via `remove_pid()`.
     - Prints recovery confirmation and returns 0 per D-11.
   - `run_doctor(args: argparse.Namespace) -> int`:
