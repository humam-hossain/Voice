# Quick Plan: Remove All Prediction and ETA Related Code

**Goal:** Completely remove all prediction, ETA calculation, and calibration code across `voice.py`, `voicemode_telemetry.py`, `voicemode_report.py`, and test suites, transitioning voicemode into a clean, low-latency chunk-streamed system without unneeded estimation overhead.

**User Decisions:**
1. Adapt `--report` into a pure stage latency report (keep audio, load, decode, finalize, and insert timings; remove predicted, actual, error %, and calibration).
2. Completely remove all `eta_*` keys from `status.json`.
3. Keep recording honest stage timings (`load_ms`, `decode_ms`, `audio_s`, `insert_ms`) in `metrics.jsonl`, but remove `predicted` and `calibration_key`.

**Files in scope:**
- `voice.py`
- `voicemode_telemetry.py`
- `voicemode_report.py`
- `tests/test_eta_engine.py` (delete)
- `tests/test_midrun_eta.py` (delete or adapt)
- `tests/test_eta_cli.py` (update/adapt)
- `tests/test_status_contract.py`
- `tests/test_telemetry.py`
- `tests/test_report.py`
- `docs/telemetry.md` (docs update)

## Tasks

### 1. Strip Prediction, ETA, and Calibration from `voicemode_telemetry.py`
- Remove calibration constants: `CALIBRATION_FILENAME`, `CALIBRATION_RESET_FILENAME`.
- Remove calibration file/state functions: `get_calibration_path`, `get_calibration_reset_path`, `get_calibration_reset_timestamp`, `reset_calibration`, `load_calibration`, `save_calibration`, `_is_calibration_excluded`, `resolve_calibrated_rate`, `update_calibration_from_run`, `rebuild_calibration_from_ledger`, `fit_calibration_from_ledger`.
- Remove ETA prior constants & estimators: `PRIOR_LOAD_S`, `PRIOR_RTF`, `PRIOR_FINALIZE_S`, `PRIOR_INSERT_S`, `prior_eta_seconds`, `calibrated_eta_seconds`, `extract_hierarchy_keys`, `calibration_key`.
- In status contract:
  - Remove `"eta_epoch"`, `"eta_remaining_s"`, `"eta_confidence"`, `"eta_source"`, `"overrun"` from `STATUS_ALLOWED_KEYS`.
  - Remove ETA params & handling from `build_status()` and `validate_status()`.
- In ledger record schema:
  - Remove `"predicted"` and `"calibration_key"` from `RECORD_ALLOWED_KEYS`.
  - Remove `NESTED_KEYS["predicted"]` and `_empty_predicted()`.
  - Clean `build_record()` to omit `predicted` and `calibration_key_val`.

### 2. Strip ETA and Prediction Logic from `voice.py`
- Remove helper functions: `update_midrun_eta`, `format_eta_pill`, `calculate_countdown_display`, `_compute_eta`.
- In `run_background_recording()`:
  - Remove `predicted` dictionary from `run_state`.
  - Remove `midrun_state` tracking and all hysteresis / ETA recalculation in `_on_segment_yield`.
  - Remove all `eta_*` arguments from `_publish_status` calls (in `starting`, `recording`, `transcribing`, `typing`).
  - Remove `voicemode_telemetry.update_calibration_from_run(record)` calls.
- In `print_status()`:
  - Remove all `eta_*`, `overrun`, `revision_count`, `last_revised_at`, `key_level`, `key_n` from the JSON dictionary.
- In CLI parser and dispatch:
  - Remove `--reset-calibration` argument from `parse_args()`.
  - Remove `--reset-calibration` handler in `main()`.

### 3. Adapt `voicemode_report.py` to Pure Stage Latency Report
- Update CSV headers: remove `predicted_s`, `actual_s`, `error_s`, `error_pct`, `eta_source`, `confidence`.
- Update terminal summary:
  - Title: "Voice Latency Report".
  - Metrics: Total Runs, Median Wait Latency, P90 Latency, Mean Real-Time Factor (RTF).
  - Table: `AUDIO`, `WAIT_S`, `RTF`, `STATUS`, `LOAD / DECODE / FINALIZE / INSERT`.
- Update HTML / SVG:
  - Replace prediction parity plot with latency / stage breakdown or RTF distribution.
  - Remove accuracy color bands (<15%, 15-30%, >30%).
- Remove prediction-vs-actual error calculations (`error_s`, `error_pct`).

### 4. Update Tests and Verify
- Remove obsolete ETA tests: `tests/test_eta_engine.py` and `tests/test_midrun_eta.py`.
- Update `tests/test_eta_cli.py` to `tests/test_status_cli.py` (verifying status contract has no ETA fields, `--reset-calibration` rejected).
- Update `tests/test_status_contract.py`, `tests/test_telemetry.py`, `tests/test_report.py`.
- Run full pytest test suite with `uv run pytest`.
- Verify CLI commands: `uv run python3 voice.py --report`, `uv run python3 voice.py --status --json`.
