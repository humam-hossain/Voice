# Quick Plan: Add `--cancel` Command and Hyprland `Super + Alt + M` Cancel Keybind

**Goal:** Add a dedicated `--cancel` CLI command to cancel active speech-to-text recording mid-sentence without transcribing or typing, bind `SUPER + ALT + M` in Hyprland to trigger `--cancel` (replacing the mute shortcut), install the keybind into `~/.config/hypr/custom/keybinds.lua`, and provide an observable, end-to-end testing workflow for both audio chunking and cancellation.

**Files in scope:**
- `voice.py`
- `tests/test_hyprland_daemon.py`
- `~/.config/hypr/custom/keybinds.lua`

## Tasks

### Task 1: Add `--cancel` command in `voice.py`
- Add `--cancel` argument to `parse_args()`.
- Implement `cancel_recording(args: argparse.Namespace) -> int`:
  - Read `PID_FILE` state.
  - If a recording process is alive:
    - Send `signal.SIGTERM` to trigger clean cancel handling in `run_background_recording`.
    - Clean up PID lock.
    - Play stop cue and show notification: `Recording cancelled.`
    - Return 0.
  - If no active recording: report `No active voice recording to cancel.` and return 0.
- Dispatch `args.cancel` in `main()`.

### Task 2: Update Hyprland Lua block in `generate_hyprland_block()`
- Add `hl.unbind("SUPER + ALT + M")`.
- Add `hl.bind("SUPER + ALT + M", hl.dsp.exec_cmd(HOME .. "/.local/bin/voice --cancel"), { description = "Voice STT: Cancel recording" })`.
- Run installation to update `~/.config/hypr/custom/keybinds.lua` and trigger `hyprctl reload`.

### Task 3: Unit tests & verification
- Update `tests/test_hyprland_daemon.py` to verify:
  - `generate_hyprland_block()` includes `SUPER + ALT + M` unbind and bind for `--cancel`.
  - `cancel_recording()` sends `SIGTERM`, removes PID, notifies, and returns 0 when recording is active.
  - `cancel_recording()` handles idle/missing process gracefully.
- Run full test suite with `uv run python -m unittest discover tests`.

### Task 4: Provide verification & testing instructions
- Provide clear instructions to test audio chunking via `voice --watch` and `VOICE_CHUNK_SECONDS=10`.
- Provide instructions to test `SUPER + ALT + M` cancellation live.
