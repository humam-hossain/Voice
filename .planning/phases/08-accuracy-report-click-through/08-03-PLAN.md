<assumptions_and_edge_probes>
- RPT-04 (Worker failure isolation probe): When report generation throws (e.g. disk full or corrupted template), `finalize_background_run()` catches the error, logs to `sys.stderr`, and safely unlinks the PID file. The user's typed transcript is already delivered and future recordings are never wedged.
- RPT-06 (Adjacency probe): If target path is exactly the state directory root rather than a file, `open_report_file()` checks `target.is_file()` and rejects directory targets.
- RPT-06 (Empty/null input probe): If path is None, empty string, or points to a non-existent file, `open_report_file()` safely prints a message to stderr, fires desktop notification fallback, and returns `False` without throwing an unhandled exception.
</assumptions_and_edge_probes>
