<objective>
Implement the self-contained, zero-JavaScript, dark-themed offline HTML dashboard generator in `voicemode_report.py`. The dashboard delivers 4 fluid responsive inline SVG charts (Predicted vs Actual scatter, Error % Over Time trend, Residual Histogram, Stage Breakdown stacked bars), 4 hero metric cards, an interactive recent runs table (25 in view, scrollable to 200), a visual onboarding empty state with ghost chart outlines and `SUPER+SHIFT+M` prompt, and a structured 4-subpanel privacy footer.

Purpose: Provide an offline visual proof of ETA honesty that users can open on demand, completely free of network dependencies, tracking, or scripts, satisfying RPT-02 and RPT-03.
Output:
- Pure f-string SVG generation functions in `voicemode_report.py`
- Pure f-string standalone HTML document generator in `voicemode_report.py`
- Hermetic test cases in `tests/test_report.py` validating SVG geometry, zero-JS compliance, empty state, and privacy sub-panels
</objective>
