<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk JSONL -> Memory | Ledger records read from `metrics.jsonl` into Python dictionaries |
| Telemetry -> CLI / Filesystem | Aggregated metrics exported to terminal, CSV, or JSON files |
| User CLI Input -> Filter Engine | User parameters passed via `--since`, `--last`, `--model`, `--device`, `--output` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-03 | Denial of Service | `voicemode_report:load_ledger_records` | medium | mitigate | Parse each JSONL line in isolated `try ... except json.JSONDecodeError`; increment `skipped_count` and continue without crashing (D-21) |
| T-08-04 | Information Disclosure | `voicemode_report:record_to_csv_row` | high | mitigate | Operate strictly on numeric timings, character counts, and model parameters; never write transcript text, prompts, hotwords, or clipboard text to CSV/JSON (LED-04, RPT-05) |
| T-08-05 | Tampering / File Overwrite | `voicemode_report:handle_report_command` | medium | mitigate | Ensure `--output` path resolution does not overwrite system files unless user explicitly specifies target path |
</threat_model>
