<assumptions_and_edge_probes>
- Tabular Figures Probe: OpenType font feature `font.features: { "tnum": 1 }` on `Appearance.font.family.numbers` guarantees equal glyph advance widths for all numerals (0-9), preventing horizontal bar jitter as elapsed seconds increment.
- Opacity Latch Probe: When `isConcurrentlyDecoding` or recording finishes, any running color or opacity animation must reset clean. `pulseAnimation` already includes `onRunningChanged: if (!running) voiceIcon.opacity = 1.0;`, and `pulsedColor` must switch cleanly to `skyBlue` or `colPrimary` via `currentColor`.
- Rapid Paste Latch Probe: When worker uses `--output-method paste`, text insertion finishes in ~20ms and worker exits. `Voice.qml` triggers `typingLingerTimer` (1000ms) and `VoicePill.qml` triggers `wrapUpTimer` (1500ms), ensuring the Neon Green pen glyph and final 3-bar timer remain visible and clickable for ~1.5s.
- Click Security Probe: An attacker cannot manipulate `report_path` to open `/etc/shadow` or execute an arbitrary URL; `openReport()` strictly validates that `target.startsWith(runtimeDir)` and `target.endsWith("report.html")`.
</assumptions_and_edge_probes>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QML -> Desktop Environment | Opening local files via `Qt.openUrlExternally` / `xdg-open` |
| Filesystem -> QML Ingestion | Parsing JSON from `$XDG_RUNTIME_DIR/voice-stt/status.json` via `FileView` |
| Bar UI -> CPU Resources | Timer intervals and animation loops on Hyprland bar |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-04 | Elevation of Privilege / Arbitrary Code Execution | `Voice.qml:openReport` | high | block | Explicit path validation: verify `target.startsWith(runtimeDir)` and `target.endsWith("report.html")` before invoking browser opener. Pass array arguments `["xdg-open", target]` to `execDetached` to prevent shell injection. |
| T-09-05 | Denial of Service | `Voice.qml:pollTimer` | medium | mitigate | Idle interval is throttled to 2500ms; event-driven `FileView` handles state transitions immediately via inotify. Active 100ms interval only runs during active recording or speaking. |
| T-09-06 | Tampering / Malformed Input | `Voice.qml:poll` | medium | mitigate | All JSON parsing is wrapped in `try ... catch (e) { st = null; }` with null checks on all fields before consumption. |
| T-09-07 | Repudiation / Visual State Confusion | `VoicePill.qml:voiceIcon` | low | mitigate | Reset opacity to 1.0 unconditionally on animation completion (`onRunningChanged: if (!running) voiceIcon.opacity = 1.0;`) to avoid sticking in intermediate opacity. |
</threat_model>
