## Implementation Decisions

### Live Progress Timer Display (Replacing Static Labels & ETA)
- **D-01:** Eliminate all static text strings (`"Transcribing..."`, `"Finalizing..."`, `"Typing..."`). All state progression is communicated strictly via numeric timers, glyph shifts, and color changes. — **Reversibility:** reversible.
- **D-02:** While recording (with parallel chunk decode active), the pill displays dual progress: `recorded_time | transcribed_time` (e.g., `0:08 | 0:05`), where the first value is elapsed recording duration and the second is audio transcribed to text so far. — **Reversibility:** reversible.
- **D-03:** Immediately when recording stops (worker enters transcribing phase for tail decode), the display transitions to a 3-bar progress format: `recorded_time | transcribed_time | total_time` (e.g., `0:10 | 0:07 | 0:10`). The recorded duration freezes, transcribed duration continues until it equals recorded audio, and total time tracks total elapsed wall-clock time. — **Reversibility:** reversible.
- **D-04:** During typing/text insertion, the 3-bar progress timer remains displayed until typing finishes, after which the pill returns to its default idle state (icon only or hidden). — **Reversibility:** reversible.

### Visual Identity: Glyphs, Colors & Animation
- **D-05:** State colors apply uniformly to BOTH the glyph icon and the label text (the entire pill content changes color together). — **Reversibility:** reversible.
- **D-06:** STT Transcribing / Decode state uses a dedicated Sky Blue color (e.g., `#38bdf8` / theme equivalent) across icon and text. — **Reversibility:** reversible.
- **D-07:** Typing / Text Injection state uses a dedicated Neon Green color (e.g., `#4ade80` / `#22c55e` / theme equivalent) across icon and text. — **Reversibility:** reversible.
- **D-08:** While recording and transcribing are concurrently active, the pill exhibits a dual visual indicator (alternating / breathing pulse between recording color `colPrimary` and STT Sky Blue) to signify active capture and background decode. — **Reversibility:** reversible.
- **D-09:** When recording stops and only tail STT decode remains, the color shifts fully to STT Sky Blue with `graphic_eq` (or progress glyph). — **Reversibility:** reversible.
- **D-10:** When typing/pasting starts, the glyph changes to the `edit` Material Symbol (pen icon) with Neon Green color, visually representing writing. — **Reversibility:** reversible.

### Layout Stability & Sizing
- **D-11:** Prevent horizontal bar jitter and width jumping as timers increment or separator bars appear, using tabular figures / monospaced digit formatting and stable container width sizing. — **Reversibility:** reversible.

### Click-Through Latency Report Opener
- **D-12:** Clicking the pill during transcribing, typing, or completion wrap-up opens the pre-rendered HTML latency report (`report.html`) generated by `voicemode_report.py`. Clicking during recording is inert. Hovering in clickable states displays `Qt.PointingHandCursor`. — **Reversibility:** reversible.

### File Observer & Synchronization
- **D-13:** `Voice.qml` watches `$XDG_RUNTIME_DIR/voice-stt/status.json` via Quickshell's event-driven `FileView` observer with a low-frequency polling fallback, avoiding aggressive 100ms polling while idle. — **Reversibility:** reversible.
- **D-14:** Live QML changes in `~/.config/quickshell/` are committed to `/home/pera/github_repo/.dotfiles/restow/quickshell/` and vendored to `integrations/quickshell/` in the Voice repo, with documentation marking the live dotfiles copy as authoritative. — **Reversibility:** costly — multi-repository deployment and git commit.

### Text Output Method
- **D-15:** Recommend/default to instant clipboard paste (`--output-method paste`) to eliminate letter-by-letter typing delays, while preserving the typing visual indicator during insertion. — **Reversibility:** reversible.

### the agent's Discretion
- Exact palette token mappings in `Appearance.colors` vs explicit hex constants for Sky Blue and Neon Green.
- Exact fallback mechanism when opening `report.html` if the default browser handler fails (e.g., `notify-send` desktop notification).
- Wrap-up linger duration (e.g., 1.5s) before returning to idle.

## Architecture Patterns

### 1. Dual & Triple Progress Timer State Progression (UI-01, D-01..D-04)

```mermaid
stateDiagram-v2
    [*] --> Idle: No STT active
    Idle --> Recording: PTT key pressed
    state Recording {
        [*] --> DualTimer: Parallel decode begins
        note right of DualTimer: Format: recorded | transcribed (e.g. 0:08 | 0:05)
    }
    Recording --> Transcribing: PTT key released (Tail decode)
    state Transcribing {
        [*] --> TripleTimerTail: Tail chunk decode
        note right of TripleTimerTail: Format: recorded | transcribed | total (e.g. 0:10 | 0:07 | 0:10)
    }
    Transcribing --> Typing: STT complete / text insertion
    state Typing {
        [*] --> TripleTimerTyping: Paste / wtype execution
        note right of TripleTimerTyping: Format: recorded | transcribed | total (e.g. 0:10 | 0:10 | 0:11)
    }
    Typing --> WrapUp: Worker exit
    state WrapUp {
        [*] --> Linger: 1.5s wrap-up timer
        note right of Linger: Keeps final 3-bar timer visible & clickable
    }
    WrapUp --> Idle: wrapUpTimer triggered
```

- **Dual Timer (`recording`):** Formatted as `${recordedDuration} | ${transcribedDuration}` (e.g., `0:08 | 0:05`). Elapsed recording seconds advance with wall-clock time; transcribed duration reflects total audio seconds decoded by background chunk workers [VERIFIED: 09-CONTEXT.md:17-18].
- **3-Bar Progress Timer (`transcribing`, `typing`, `wrapup`):** Formatted as `${recordedDuration} | ${transcribedDuration} | ${totalDuration}` (e.g., `0:10 | 0:07 | 0:10` -> `0:10 | 0:10 | 0:12`).
  - `recordedDuration`: Frozen at audio duration captured (from `status.json.audio_s` or elapsed recording seconds upon key release) [VERIFIED: 09-CONTEXT.md:18-19].
  - `transcribedDuration`: Advances as tail chunks finish decoding until equal to `recordedDuration`.
  - `totalDuration`: Wall-clock elapsed duration since recording started (`(Date.now() - startTime) / 1000`), continuing to tick live through transcription and insertion until wrap-up ends [VERIFIED: 09-CONTEXT.md:18-19].

### 2. State-Synchronized Visual Styling (UI-02, D-05..D-10)

All visual transitions synchronize the glyph icon and the text label to share identical colors:

| State | Glyph Icon | Hex / Token Color | Animation / Visual Feedback |
|---|---|---|---|
| **Idle** | None (pill hidden or collapsed) | `Appearance.colors.colOnLayer1` | Hidden or icon-only |
| **Recording (Pre-decode)** | `graphic_eq` | `Appearance.colors.colPrimary` (Lavender / Theme) | Subtle breathing opacity pulse |
| **Recording (Concurrent Decode)** | `graphic_eq` | Alternating / breathing pulse between `colPrimary` and Sky Blue (`#38bdf8`) | Signifies active microphone capture + parallel chunk STT decode [VERIFIED: 09-CONTEXT.md:25] |
| **Transcribing (Tail Decode)** | `graphic_eq` | Dedicated Sky Blue (`#38bdf8`) | Static Sky Blue color across both icon and text [VERIFIED: 09-CONTEXT.md:23, 26] |
| **Typing / Insertion** | `edit` (Pen glyph) | Dedicated Neon Green (`#4ade80`) | Static Neon Green representing text output [VERIFIED: 09-CONTEXT.md:24, 27] |
| **Wrap-up (Linger)** | `edit` (Pen glyph) | Dedicated Neon Green (`#4ade80`) | Final display retained for 1.5s linger window [VERIFIED: 09-CONTEXT.md:45] |

### 3. Layout Stabilization Pattern (UI-03, D-11)

In Qt Quick, proportional fonts cause width jitter when timer digits change (e.g. `1` vs `8`).
1. **Tabular Numerals & Monospaced Digits:** In `VoicePill.qml`, `voiceLabel` MUST use `Appearance.font.family.numbers` or `Appearance.font.family.monospace` [VERIFIED: Appearance.qml:217-221], with OpenType tabular numbers enabled via `font.features: { "tnum": 1 }` [ASSUMED].
2. **Smooth Width Interpolation:** `VoicePill.qml` applies a `Behavior on implicitWidth` using Material 3 250ms expressive deceleration (`Appearance.animationCurves.expressiveEffects`) so transitions between idle, dual timer, and triple timer glide without horizontal jumping [VERIFIED: VoicePill.qml:141].

### 4. Click-Through Latency Report Opener (UI-04, D-12)

- In `VoicePill.qml`, `inertMouseArea` is replaced with an interactive `MouseArea` [VERIFIED: VoicePill.qml:110-118].
- **Clickable States:** `transcribing`, `typing`, and `wrapup`.
- **Inert States:** `recording` and `idle`.
- **Hover Feedback:** `cursorShape: clickable ? Qt.PointingHandCursor : Qt.ArrowCursor` [VERIFIED: 09-CONTEXT.md:33].
- **Safe Execution & Path Validation:** `Voice.qml` validates that the target path begins with `Voice.runtimeDir` and ends with `report.html` before triggering `Qt.openUrlExternally("file://" + path)` [VERIFIED: Voice.qml:13-19, voicemode_report.py:1042-1050]. If `Qt.openUrlExternally` fails, it falls back to `Quickshell.execDetached(["xdg-open", path])` [VERIFIED: 09-CONTEXT.md:44].

### 5. Reactive FileView & Polling Decoupling (UI-03, D-13)

- `Voice.qml` binds Quickshell's event-driven `FileView` observer with `watchChanges: true` on `status.json` and `recorder.pid` [VERIFIED: MaterialThemeLoader.qml:64-68].
- An inotify signal immediately invokes `root.poll()`, providing sub-millisecond reaction when the Python worker updates state [ASSUMED].
- When idle, `pollTimer.interval` drops to a low-frequency fallback of `2500ms` (avoiding CPU wakeups), accelerating to `100ms` only during active recording or playback to drive live second increments [VERIFIED: Voice.qml:330].

## Don't Hand-Roll

| Capability | What NOT to do | Recommended Solution | Reason |
|---|---|---|---|
| **Inotify / File Watching** | Don't poll `status.json` every 10-50ms | Use Quickshell's built-in `FileView { watchChanges: true; onFileChanged: ... }` | Inotify provides kernel-level push notifications with zero CPU spin when idle [VERIFIED: MaterialThemeLoader.qml:64-68]. |
| **Material Icons** | Don't hand-craft SVG pen/mic graphics or use non-standard Unicode strings | Use `MaterialSymbol { text: "graphic_eq" / "edit" }` | `Appearance.font.family.iconMaterial` ("Material Symbols Rounded") natively supports `"graphic_eq"` and `"edit"` [VERIFIED: MaterialSymbol.qml:12, Appearance.qml:219]. |
| **Number Formatting** | Don't parse timestamps with regex in QML | Use `Voice.formatDuration(seconds)` (`m + ":" + (s < 10 ? "0" : "") + s`) | Built-in, zero-allocation helper already verified in `Voice.qml:57-61` [VERIFIED: Voice.qml:57-61]. |
| **Report Generation** | Don't run ad-hoc Python child processes to create HTML upon clicking | Open the pre-rendered `$XDG_RUNTIME_DIR/voice-stt/report.html` | Pre-rendered atomically by `voicemode_report.generate_prerendered_report()` at worker completion [VERIFIED: voice.py:1230-1235, voicemode_report.py:996-1011]. |
| **Desktop Url Launching** | Don't execute raw shell strings (`sh -c ...`) | Use `Qt.openUrlExternally()` or `Quickshell.execDetached(["xdg-open", path])` | Avoids shell injection vulnerabilities and respects Hyprland default desktop browser bindings [VERIFIED: voicemode_report.py:1052-1055, NotificationItem.qml:71]. |

## Common Pitfalls

### Pitfall 1: Worker Tail-Decode Transcribed Duration Freeze
- **Symptom:** When recording stops, the pill transitions to the 3-bar progress timer, but `transcribed_time` remains frozen at whatever chunks were decoded during recording, never advancing as remaining chunks decode.
- **Root Cause:** In `voice.py:2316-2331`, when `capture_closed.is_set()` is true, `_publish_status("transcribing", "decode", segments=tot, segments_done=done)` does NOT recalculate or pass `transcribed_audio_s`! It was only computed in the `else` branch (while recording) [VERIFIED: voice.py:2316-2331].
- **Mitigation:** Calculate `transcribed_s = sum(r.audio_s for r in results.values() if r and getattr(r, "audio_s", None))` unconditionally before branching, and pass `transcribed_audio_s=transcribed_s` during tail decode. In addition, when all chunks finish in `voice.py:2499-2501` (`typing` state), explicitly publish `transcribed_audio_s=d, audio_s=d` so `transcribed_audio_s == audio_s` is guaranteed.

### Pitfall 2: Bar Jitter from Variable Digit Widths
- **Symptom:** As digits tick (e.g. `0:08 | 0:05` -> `0:09 | 0:05`), the entire pill and adjacent bar widgets shift left and right by 1 to 3 pixels every second.
- **Root Cause:** Standard sans-serif proportional fonts allocate different horizontal widths to digits like `1` vs `8`. `StyledText.qml:12` only uses the number font if the string matches `/^\d+$/`, which fails for strings with pipes and colons [VERIFIED: StyledText.qml:12-14].
- **Mitigation:** In `VoicePill.qml`, explicitly set `font.family: Appearance.font.family.numbers` (or monospace) and `font.features: { "tnum": 1 }` on `voiceLabel`, ensuring every numeral occupies identical monospace pitch [VERIFIED: Appearance.qml:217-221].

### Pitfall 3: Flash of Disappearance on Instant Paste
- **Symptom:** When using `--output-method paste`, text insertion completes in 10-30 ms, causing the typing state to terminate before Quickshell even renders the green pen glyph.
- **Root Cause:** Worker exits and clears `recorder.pid` and `status.json` immediately after insertion [VERIFIED: voice.py:1088-1102].
- **Mitigation:** `Voice.qml` already contains `typingLingerTimer` (1000ms) [VERIFIED: Voice.qml:116-125] and `VoicePill.qml` contains `wrapUpTimer` (1500ms) [VERIFIED: VoicePill.qml:77-81]. When worker drops PID lock from `transcribing` or `typing`, `Voice.qml` transitions `sttState` to `typing` and restarts `typingLingerTimer`, ensuring the user clearly sees the green pen icon and final triple-timer display before returning to idle.

### Pitfall 4: Path Traversal in Report Opener
- **Symptom:** Malicious or malformed status file points `report_path` to an arbitrary filesystem path or executable.
- **Root Cause:** Trusting untrusted string from status payload without directory constraints.
- **Mitigation:** Validate in `Voice.qml` that `reportPath.startsWith(Voice.runtimeDir)` and `reportPath.endsWith("report.html")` prior to passing to `Qt.openUrlExternally` [VERIFIED: Voice.qml:13-19, voicemode_report.py:1042-1050].

### Pitfall 5: Multi-Repo Desynchronization
- **Symptom:** Changes tested in `~/.config/quickshell/` work locally but are lost upon `stow` or when the user clones `Voice` on another system.
- **Root Cause:** `~/.config/quickshell/` files are symlinked to `/home/pera/github_repo/.dotfiles/restow/quickshell/...` [VERIFIED: `ls -la ~/.config/quickshell/...`]. The Voice repository does not automatically track dotfile changes unless vendored.
- **Mitigation:** Strictly execute the two-repo synchronization workflow (UI-05, D-14): edit and commit in `.dotfiles`, copy to `integrations/quickshell/` in `Voice`, and document the live dotfiles copy as authoritative.

### Pitfall 6: Opacity Latch in Breathing Pulse
- **Symptom:** When recording stops, `voiceIcon` gets stuck at 0.5 opacity during transcribing or typing.
- **Root Cause:** An interrupted `NumberAnimation` leaves `target.opacity` at its intermediate value [VERIFIED: VoicePill.qml:153-154].
- **Mitigation:** Guard `onRunningChanged: if (!running) voiceIcon.opacity = 1.0;` on all pulse animations [VERIFIED: VoicePill.qml:153-154].

### 1. `Voice.qml` - Duration Tracking & Multi-Bar Timers

```qml
// In /home/pera/github_repo/.dotfiles/restow/quickshell/.config/quickshell/ii/services/Voice.qml
// Timers & Durations
property int elapsedSeconds: 0
property real elapsedMs: 0
property string formattedDuration: "0:00"
property real startTime: 0

// Phase 9 Multi-Timer Properties
property real recordedAudioSeconds: 0.0
property string formattedRecordedDuration: "0:00"
property real transcribedAudioSeconds: 0.0
property string formattedTranscribedDuration: "0:00"
property int totalElapsedSeconds: 0
property string formattedTotalDuration: "0:00"

readonly property string defaultReportPath: runtimeDir + "/report.html"
property string statusReportPath: ""

function formatDuration(sec) {
    const sInt = Math.max(0, Math.floor(sec));
    const m = Math.floor(sInt / 60);
    const s = sInt % 60;
    return m + ":" + (s < 10 ? "0" : "") + s;
}

function updateDuration() {
    if (overallState === "recording" || overallState === "speaking") {
        if (startTime <= 0) {
            const activePid = (overallState === "recording") ? sttPid : ttsPid;
            startTime = Math.min(Date.now(), recoverStartTime(activePid));
        }
        const diff = Math.max(0, Date.now() - startTime);
        elapsedMs = diff;
        elapsedSeconds = Math.floor(diff / 1000);
        formattedDuration = formatDuration(elapsedSeconds);
        formattedRecordedDuration = formattedDuration;
        totalElapsedSeconds = elapsedSeconds;
        formattedTotalDuration = formattedDuration;
    } else if (overallState === "transcribing" || overallState === "typing") {
        // Recorded duration remains frozen; wall-clock total continues ticking
        if (startTime > 0) {
            const totalDiff = Math.max(0, Date.now() - startTime);
            totalElapsedSeconds = Math.floor(totalDiff / 1000);
            formattedTotalDuration = formatDuration(totalElapsedSeconds);
        }
    } else if (overallState === "idle" && !typingLingerTimer.running) {
        resetDuration();
    }
}

function openReport() {
    const target = statusReportPath.length > 0 ? statusReportPath : defaultReportPath;
    if (target.startsWith(runtimeDir) && target.endsWith("report.html")) {
        const opened = Qt.openUrlExternally("file://" + target);
        if (!opened) {
            Quickshell.execDetached(["xdg-open", target]);
        }
    }
}
```
