# Plan 11-01: Core Configuration Backend & VoicePopup Overlay Foundation

## Executive Summary

This plan implements the configuration persistence backbone in `voice.py`, unit test validation in `tests/test_config.py`, and the foundational `VoicePopup.qml` desktop overlay component. The overlay equips the desktop bar with instant action buttons (Start, Stop, Cancel), real-time live telemetry display, 12 interactive persistent configuration controls syncing directly to `~/.config/voicemode/config.json`, and a scrollable recent runs card with an "Open Full Report" button.

---

## Threat Model (ASVS Level 1)

<threat_model>
- **T-11-01: Insecure Configuration File Permissions & Data Leakage**
  - *Risk:* If `~/.config/voicemode/config.json` is world-readable or stored in a shared directory, other local users could inspect configuration or tamper with runtime flags.
  - *Mitigation:* `get_config_dir()` enforces `0700` (`rwx------`) directory permissions. `save_user_config()` creates temporary files with `0600` (`rw-------`) before atomic rename. Neither `config.json` nor `metrics.jsonl` ever contains transcript text, prompts, hotwords, or clipboard content.
- **T-11-02: Race Conditions & Partial Writes during Configuration Save**
  - *Risk:* Concurrent toggles or sudden power loss could produce truncated or invalid JSON, breaking the parser.
  - *Mitigation:* Python writes via `tempfile.mkstemp` + `os.replace`. Quickshell QML writes via `FileView.setText()` which uses Qt `QSaveFile` (temp file + rename).
- **T-11-03: Subprocess Injection Hazards in QML**
  - *Risk:* Invoking shell strings like `sh -c "voice --toggle"` opens arbitrary command execution vectors if arguments contain unescaped user inputs.
  - *Mitigation:* `VoicePopup.qml` strictly dispatches `Quickshell.execDetached(["voice", "--toggle"])` and `Quickshell.execDetached(["voice", "--cancel"])` using string argument arrays directly to the binary.
- **T-11-04: Arbitrary File / URL Invocation via Report Opener**
  - *Risk:* Unrestricted report opening could launch arbitrary local scripts or external web pages.
  - *Mitigation:* The "Open Full Report" button delegates exclusively to `Voice.openReport()`, which enforces path validation: target must start with `runtimeDir` and end with `report.html` before passing to `Qt.openUrlExternally`.
</threat_model>
