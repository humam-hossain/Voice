<threat_model>
## ASVS Level 1 Threat Analysis

- **T-05-05: Insecure Audio Device Permissions or Systemd Scope Creep (ASVS 1.1.5 - Privilege Escalation)**
  - *Description:* Setup guides suggesting `sudo` commands or granting root access to user-space audio/input devices create severe privilege escalation vectors.
  - *Severity:* High
  - *Mitigation:* Documentation strictly specifies rootless, unprivileged operation. Keystroke injection operates via `wtype` (`zwp_virtual_keyboard_v1`) without root/daemon requirements, and audio capture/playback utilizes standard user-space PipeWire/WirePlumber sessions.
- **T-05-06: Malicious or Outdated Dependency Advice (ASVS 14.2.1 - Dependency Tampering)**
  - *Description:* Directing users to unverified third-party repositories or out-of-date AUR helpers could result in installing malicious package variants.
  - *Severity:* Medium
  - *Mitigation:* All documented system packages (`wtype`, `ffmpeg`, `wireplumber`, `wl-clipboard`, `hyprland`) are sourced strictly from official Arch Linux repositories (`extra`), and models are pulled from verified HuggingFace repositories with exact size validation.
- **T-05-07: Stow Dotfile Symlink Destruction via Misleading Documentation (ASVS 8.3.1 - Data Loss)**
  - *Description:* Instructing users to write directly to `~/.config/hypr/custom/keybinds.lua` without explaining symlink preservation risks severing GNU Stow symlinks and disconnecting version-controlled dotfiles.
  - *Severity:* High
  - *Mitigation:* Documentation clearly details GNU Stow symlink preservation, explains how `voice --install-hotkey` modifies the resolved destination in-place, and provides exact configuration snippets for manual dotfiles management.
</threat_model>
