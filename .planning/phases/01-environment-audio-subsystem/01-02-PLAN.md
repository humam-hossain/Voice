# Plan 01-02: Audio Subsystem & Whisper CPU Defaults

## Executive Summary

Plan 01-02 implements and validates the audio capture and STT inference pipeline for `voicemode` on Arch Linux over PipeWire. It optimizes Faster-Whisper for low-latency CPU push-to-talk transcription (`small.en`, `int8`, `beam_size=1`, `vad_filter=True`), configures direct 16 kHz mono PortAudio capture with software resampling fallback (`np.interp`), tags audio streams with client name `voicemode`, enhances auditory cues with a 70ms synchronous lead-in start chime and asynchronous stop chime thread, introduces a 300s safety duration ceiling, and pre-downloads and validates the model cache.

## Artifacts this phase produces

- `/home/pera/github_repo/Voice/voice.py` (Updated STT defaults, 16 kHz capture, cue architecture, safety duration, and stream naming)
- `/home/pera/.cache/huggingface/hub/models--Systran--faster-whisper-small.en/` (Pre-cached Faster-Whisper `small.en` model weights)

## ASVS Level 1 Threat Analysis

- **Threat 1: Denial of Service via Unbounded Recording Duration (ASVS 11.1.4)**
  - *Description:* A stuck or unattended recording process could run indefinitely, filling disk storage with uncompressed audio and exhausting CPU memory during transcription.
  - *Severity:* Medium
  - *Mitigation:* Implement a hard 300-second (5-minute) safety ceiling (`MAX_RECORDING_SECONDS = 300.0`) in the recording event loop per D-12 to automatically stop recording and initiate transcription.
- **Threat 2: Insecure Temporary File Creation & Information Disclosure (ASVS 12.3.1)**
  - *Description:* Temporary WAV audio files containing sensitive microphone audio could be exposed to other local users if created with insecure file permissions in `/tmp`.
  - *Severity:* Medium
  - *Mitigation:* Temporary WAV files are created using `tempfile.NamedTemporaryFile` with user-exclusive read/write permissions (0600) and unlinked immediately in `finally` blocks after transcription.
- **Threat 3: Untrusted Model Loading / Code Execution (ASVS 10.3.2)**
  - *Description:* Arbitrary model downloads could lead to code execution if deserializing pickled Python weights.
  - *Severity:* High
  - *Mitigation:* Faster-Whisper utilizes CTranslate2 native binary weights downloaded from official Hugging Face repository (`Systran/faster-whisper-small.en`) with cryptographic hash checking rather than Python `pickle` objects.
</threat_model>

   ```python
   def resample_pcm(audio: np.ndarray, orig_sr: int, target_sr: int = 16000) -> np.ndarray:
       """Resample 1D or 2D audio array from orig_sr to target_sr using linear interpolation."""
       if orig_sr == target_sr:
           return audio
       num_samples = int(round(len(audio) * float(target_sr) / orig_sr))
       orig_idx = np.arange(len(audio))
       target_idx = np.linspace(0, len(audio) - 1, num_samples)
       if audio.ndim > 1:
           resampled = np.empty((num_samples, audio.shape[1]), dtype=audio.dtype)
           for ch in range(audio.shape[1]):
               resampled[:, ch] = np.interp(target_idx, orig_idx, audio[:, ch])
           return resampled
       return np.interp(target_idx, orig_idx, audio).astype(audio.dtype)
   ```
5. Enhance `Recorder` class in `voice.py`:
