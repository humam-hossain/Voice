| T-10-07 | Information Disclosure | Doctor output or JSON diagnostics leak absolute paths or sensitive environment details. | Restrict path reporting to standard directory names and permission octals; avoid logging full file lists or usernames. |
| T-10-08 | Tampering / XSS | Malicious or unexpected run ID or outlier reason strings inject HTML/SVG into report.html. | Sanitize all dynamic strings using html.escape() before inserting into SVG title attributes or HTML template tags. |
