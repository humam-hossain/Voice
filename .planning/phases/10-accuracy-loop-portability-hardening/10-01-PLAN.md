<threat_model>
<trust_boundaries>
- Local filesystem permissions boundary: $XDG_STATE_HOME/voice-stt/corpus/ (0700) and WAV files (0600).
- Subprocess execution boundary: audio recording and wtype keystroke typing.
- Network boundary: Zero network calls. Corpus capture is entirely local and offline.
</trust_boundaries>

<stride_register>
| Threat ID | STRIDE Category | Threat Description | Mitigation Strategy |
|---|---|---|---|
| T-10-01 | Information Disclosure | Non-standard UID fallback to /tmp/voice-stt-$UID/ could expose audio or metrics to other local users if world-readable. | Enforce POSIX permissions 0700 via os.chmod on state_dir and 0600 on created files; embed os.getuid() in path. |
| T-10-02 | Denial of Service | Diagnostic audio corpus fills disk space, causing system instability. | Strict 1 GB filesystem free-space check before writing; strict FIFO quotas (max 50 files / 100 MB) with inline pruning. |
| T-10-03 | Information Disclosure | Captured corpus audio leaks user speech or discloses user home directory in metrics. | Corpus capture is opt-in (default none); files stored with 0600 permissions; ledger records relative path only (corpus/{filename}); zero network calls. |
| T-10-04 | Denial of Service | Full disk (ENOSPC) or read-only directory (EROFS) crashes dictation. | Catch OSError around all telemetry and status writes; fall back to in-memory float32 numpy array transcription in Recorder and transcribe_timed. |
| T-10-05 | Denial of Service | Desktop notifications or audio cues on outlier detection steal active window focus before/during wtype keystroke typing. | Outliers operate strictly under focus-safe policy: zero desktop toasts, zero audio beeps, zero window focus interactions. |
</stride_register>
