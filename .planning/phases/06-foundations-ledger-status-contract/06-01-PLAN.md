## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell env → process | `XDG_RUNTIME_DIR`, `XDG_STATE_HOME`, `VOICE_METRICS` are attacker-controllable if a wrapper script is; paths decide where private data lands |
| worker process → filesystem | ledger/status/pid files are read by other processes and by future QML |
| future reader → ledger | JSONL parsed by report/QML; malformed rows must not crash a reader |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information Disclosure | `get_metrics_dir()` / `get_state_dir()` | high | mitigate | mkdir with `0o700` and chmod on every call; ledger/status/pid written `0o600` via `mkstemp` + explicit `chmod` before `os.replace`; asserted by `test_ledger_file_mode_0600_and_dir_0700` |
| T-06-02 | Tampering | `atomic_write_text`/`atomic_write_json` | medium | mitigate | temp file created in the destination directory, `os.replace` for the rename, temp unlinked on failure; no partial status.json can exist |
| T-06-03 | Denial of Service | `main()` import path | medium | mitigate | heavy modules (`numpy`, `sounddevice`, `faster_whisper`, `asyncio`, `traceback`) imported only inside the functions that use them; `test_import_light.py` fails the build if any sneak back to module scope |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed in this phase (no new dependencies per CONTEXT/REQUIREMENTS). If an executor proposes a new dependency, stop and return `## CHECKPOINT REACHED` instead of installing. |
