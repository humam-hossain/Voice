     - Time the inner `_decode(state)` from immediately before `state.model.transcribe` through the full materialization of segments: `segments = list(raw_segments)`.
     - Record `decode_ms = round((time.monotonic() - t0) * 1000.0, 3)` after the list is completely materialized.

     - Return `TranscriptionEvidence(...)`.
   - Update `transcribe()` to be a thin wrapper: `ev = transcribe_timed(...); return (ev.text, ev.model_state)`.

   - Add `self.on_chunk_ready: Optional[Callable[[int, Path, Optional[float]], None]] = None` in `__init__`.
   - In `_write_chunk_async`: record `self._chunk_audio_s[idx] = audio_s`, then after releasing lock invoke `self.on_chunk_ready(idx, wav_path, audio_s)` safely inside try/except.

  <name>Task 2: Worker consumer queue, early model load, concurrent chunk decoding, and text assembly</name>
  <files>voice.py</files>
  <action>
1. At module scope: ensure `import queue` is present.
2. In `run_background_recording`:
   - Initialize before `recorder.start()`:
     `chunk_queue = queue.Queue()`, `chunk_lock = threading.Lock()`, `enqueued = {}`, `results = {}`, `results_lock = threading.Lock()`, `stop_event = threading.Event()`, `capture_closed = threading.Event()`, `loader_state = {"load_ms": None, "fallback_load_ms": None, "error": None, "backend": None}`, `total_chunks_holder = {"n": None}`, `consumer_fatal = []`, `model_holder = {"state": None}`.
   - Set `recorder.on_chunk_ready = _enqueue`.
   - Launch consumer thread `consumer = threading.Thread(target=_consume, daemon=True)` immediately after `recorder.start()`.
   - In `_consume()`:
     - Publish status: `publish_status("recording", "load")` (or `"transcribing", "load"` if capture already closed).
     - Load model early: `t_load = time.monotonic(); model_holder["state"] = load_model(args); loader_state["load_ms"] = round((time.monotonic() - t_load) * 1000.0, 3)`.
     - Loop getting items from `chunk_queue`:
       - For each `(idx, path, audio_s)`:
         - Arm watchdog Timer.
         - Decode chunk via `transcribe_timed(model_holder["state"], path, args, initial_prompt=initial_prompt, audio_s=audio_s)`.
         - Store evidence in `results[idx]`. If fallback occurred, update `model_holder["state"] = evidence.model_state`.
         - Disarm watchdog Timer.
         - If temporary file, unlink path.
         - Update status progress `update_status(segments=max(existing_segments, done), segments_done=done)` without publishing unless capture_closed and heartbeat interval passed.
   - When recording stops (`stop_requested` or ceiling):
     - Publish `transcribing/finalize`, set `capture_closed.set()`.
     - Finalize WAV: `raw_paths, duration, should_delete = recorder.stop_to_wav(args.save_dir)`.
     - Set `total_chunks_holder["n"] = len(wav_paths)`.
     - Enqueue returned paths into `chunk_queue`, then enqueue sentinel `None`.
     - `consumer.join()`.
     - Assemble text from `sorted(results.items())`, joining texts or inserting `SKIPPED_SEGMENT_MARKER` for failed chunks.
     - Proceed to typing/clipboard insertion.
  </action>
</task>

   - Cleanup:
     - Remove `status.json` only if it belongs to this run (`status.get("run_id") == run_state["run_id"]` or absent).

   - If `voicemode_telemetry.get_metrics_enabled()` is True:

     - Append row to ledger via `voicemode_telemetry.append_ledger_row(...)`.
   - Return True if row written. Never raise.

   - Accept `run_state` parameter.
   - When watchdog triggers: call `finalize_background_run(run_state, outcome="watchdog_timeout", error_stage="Whisper transcription")` BEFORE calling `os._exit(1)`.

     - Clean up stale status and PID file.
   - Call `reconcile_abandoned_run()` inside `toggle_background_recording` under `with_pid_lock()`.
