<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → status.json | a snapshot of run state crosses into a file read by other processes and (Phase 9) QML |
| other processes → status.json | readers trust the file for display, so stale or forged content must be rejectable |
| worker → PID file | the authority file; status must never override it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-12 | Information Disclosure | `build_status` / `publish_status` | high | mitigate | Closed `STATUS_V1_KEYS` allowlist plus `validate_status` before every write; a `text`/`transcript`/`clipboard` key raises `ValueError`; `Test_schema_is_closed_and_sized` fails the build if the allowlist is widened |
| T-06-13 | Tampering | `status.json` on disk | medium | mitigate | `atomic_write_json` (`mkstemp` + `os.replace`, mode 0600) and a 1024-byte ceiling; a reader-thread test asserts no partial snapshot is ever observable |
| T-06-14 | Spoofing | stale `status.json` after a crash | medium | mitigate | `expires_at = updated_at + 30 s` and `status_expired()`; PID file remains the authority so a leftover snapshot cannot make the bar render a live run |
| T-06-15 | Denial of Service | status publishing inside the recording loop | medium | mitigate | publish helper swallows and reports once; heartbeat is a monotonic deadline, not a sleep, and never blocks the loop; writes are a few hundred bytes via `os.replace` |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed in this phase (`math`, `json`, `time` are stdlib). A proposed dependency halts with `## CHECKPOINT REACHED`. |
</threat_model>
