`NESTED_KEYS` — `actual: {total_ms, finalize_ms, load_ms, decode_ms, insert_ms}`; `predicted: {shown_s, shown_at_epoch, source, key_level, n, confidence, revisions, actual_s}`; `segments[]: {idx, audio_s, decode_ms, chars, ok, fallback, avg_logprob, compression_ratio, no_speech_prob, temperature, vad_audio_s, error_type}`; `config: {model, device, compute_type, beam_size, vad_filter, language, chunk_s}`; `tts: {predicted_ms, actual_ms, chars, voice, backend, synth_ms, play_ms}`.

`validate_record(record)` — raises `ValueError` naming the offending key when: any top-level key is not in `SCHEMA_V1_KEYS`; any nested key is not in the matching `NESTED_KEYS` set; `record["schema"] != 1`; `record["source"] not in {"stt", "tts"}`; `record["outcome"] not in {"success","cancelled","error","watchdog_timeout","abandoned"}`; any `segments[]` item is not a dict; any value is not JSON-serialisable. `build_record(...)` — keyword-only builder returning a fully-populated dict with every `SCHEMA_V1_KEYS` entry present (use `None` for unknown numbers, `{}`→filled structs, `[]`→segments). Signature: `build_record(*, run_id, install_id, ts_start, ts_end, outcome, error_stage=None, actual=None, predicted=None, audio_s=0.0, chars_out=0, chars_typed=0, fallback_used=False, insert_ok=False, segments=None, config=None, backend=None, tts=None)`. It must coerce numbers with `float()`/`int()` and fill `actual`/`predicted`/`config`/`tts` with their full key sets defaulted to `None`/`0`, then run `validate_record`.

`get_install_id()` — read `get_state_dir()/"install_id"`; if absent, compute `hashlib.sha256(salt + b":" + machine_id).hexdigest()[:32]` where `salt` is 32 random bytes from `os.urandom` persisted at `get_state_dir()/"install_salt"` with mode `0o600` (`atomic_write_text`) and `machine_id` is `Path("/etc/machine-id").read_bytes().strip()` (a fresh `os.urandom(16)` fallback when unreadable); persist the id `0o600` and return it. Never store the raw machine-id, hostname, or username.

`calibration_key(backend, config)` — deterministic short string `f"{config['model']}|{config['device']}|{config['compute_type']}|{backend}|beam={config['beam_size']}|vad={int(bool(config['vad_filter']))}|lang={config['language']}|chunk={config['chunk_s']}"`. Document in the module docstring that this is the portability key used by Phase 7.

`tts_reserved()` — returns the `tts` struct with every field `None` (LED-05: fields reserved, no TTS data written in this milestone).

`source` discriminator is required on every row (`"stt"` today); no TTS code path may call `build_record` with `source="tts"` in this phase — add a comment stating so.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → ledger file | measured values (possibly derived from transcript) cross into durable storage |
| ledger file → report/QML readers | stored rows are re-read by later phases and by `--doctor` |
| env → telemetry | `VOICE_METRICS`/`VOICE_TELEMETRY`/`XDG_*` decide whether and where data lands |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Information Disclosure | `build_record` / `append_ledger_row` | high | mitigate | Fixed `SCHEMA_V1_KEYS` allowlist enforced by `validate_record` on every append; regex scan test fails the build on `/home/`, `/tmp/`, email, `@host`, or a transcript sentinel appearing in a row |
| T-06-05 | Information Disclosure | `get_install_id` | medium | mitigate | Store only `sha256(salt + machine-id)` truncated to 32 hex chars; salt 32 random bytes persisted `0600`; raw machine-id/hostname/username never written; asserted by `TestInstallId` |
| T-06-06 | Tampering | ledger rotation | medium | mitigate | `os.replace` rename of a timestamped archive; archives are never deleted; rename failure falls back to appending in place rather than dropping the row |
| T-06-07 | Denial of Service | `read_ledger_rows` on a torn line | low | mitigate | Blank/non-JSON/non-v1 lines are skipped, never raised; covered by the rotation test |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed in this phase. `hashlib`/`os.urandom` are stdlib. Any proposed dependency halts the plan with `## CHECKPOINT REACHED`. |
</threat_model>
